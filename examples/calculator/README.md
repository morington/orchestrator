# Пример: калькулятор из двух сервисов

Этот пример показывает оркестратор в работе на простой цепочке из двух шагов.

Мы отправляем арифметические выражения (`2+2`, `6-9*8`, ...). Каждое проходит через
два микросервиса:

1. `service.calc` — вычисляет выражение и возвращает число.
2. `service.assemble` — берёт исходное выражение и число и собирает строку
   `Ответ на пример (<выражение>): <число>`.

Готовый ответ возвращается клиенту через событие `orchestrator.workflow.completed`.
Клиент отправляет все выражения сразу и не ждёт ответ на каждое — ответы печатаются по
мере готовности, асинхронно.

## Что внутри

```
calculator/
├── docker-compose.yml          # postgres + nats + миграции + оркестратор + 2 сервиса
├── client.py                   # отправляет выражения и печатает ответы
└── services/
    ├── common.py               # сборка ответа шага
    ├── calculator.py           # service.calc
    └── assembler.py            # service.assemble
```

## Пайплайн

Клиент формирует для каждого выражения такую декларацию (`build_pipeline` в `client.py`):

```json
{
  "definition_key": "calculator",
  "outputs": {"answer": {"ref": "$2:text", "required": true}},
  "steps": [
    {"step_id": 1, "meta": {"target": "service.calc"}, "data": {"expression": "6-9*8"}},
    {"step_id": 2, "meta": {"target": "service.assemble"},
     "depends_on": [{"node": 1, "policy": "requires_success"}],
     "data": {"expression": "6-9*8", "value": "$1:value"}}
  ]
}
```

`$1:value` подставляет в шаг 2 поле `value` из результата шага 1. `outputs.answer`
берёт `text` из результата шага 2 — это и есть готовая строка ответа.

## Запуск

Из корня репозитория должен быть `.env` (`cp .env.example .env`). Затем:

```bash
cd examples/calculator
docker compose up -d --build
```

Поднимутся PostgreSQL, NATS, контейнер миграций, оркестратор и оба сервиса. Когда всё
готово, отправьте выражения с хоста:

```bash
cd ../..
uv run python examples/calculator/client.py "2+2" "6-9*8" "10/4" "(3+5)*2" "100-1"
```

Ожидаемый вывод (порядок зависит от того, какой пример посчитался первым):

```
Отправлено примеров: 5. Ждём ответы...

Ответ на пример (2+2): 4
Ответ на пример (6-9*8): -66
Ответ на пример (10/4): 2.5
Ответ на пример ((3+5)*2): 16
Ответ на пример (100-1): 99
```

Без аргументов клиент отправит набор по умолчанию.

## Остановка

```bash
cd examples/calculator
docker compose down -v
```
